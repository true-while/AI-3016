# AI-3016: Building Generative AI Solutions with Azure OpenAI Service

## Overview

This repository contains lab exercises and resources for the **AI-3016** course: *Building Generative AI Solutions with Azure OpenAI Service*. This course provides hands-on experience with Azure OpenAI Service, covering prompt engineering, retrieval-augmented generation (RAG), and building intelligent applications.

---

## Prerequisites

Before attending this course, participants should have:

- **Azure Subscription**: An active Microsoft Azure subscription with access to Azure OpenAI Service.
- **Programming Knowledge**: Basic experience with Python or another programming language.
- **Azure Fundamentals**: Familiarity with the Azure portal and basic Azure services (equivalent to AZ-900 or hands-on experience).
- **AI/ML Concepts**: A basic understanding of artificial intelligence and machine learning concepts.
- **Development Environment**: A computer with an internet connection and the ability to run Python scripts or Jupyter notebooks.
  - Recommended: [Visual Studio Code](https://code.visualstudio.com/) with the Python extension
  - Python 3.8 or later installed
  - Git installed

---

## Agenda

### Module 1: Introduction to Azure OpenAI Service
- Overview of Azure OpenAI Service capabilities
- Setting up and configuring Azure OpenAI resources
- Exploring available models (GPT-4, GPT-3.5, DALL-E, etc.)

### Module 2: Prompt Engineering
- Principles of effective prompt design
- System messages and few-shot examples
- Techniques for controlling model behavior and output

### Module 3: Working with the Azure OpenAI API
- Authentication and SDK setup
- Making completions and chat completions requests
- Handling responses and managing tokens

### Module 4: Retrieval-Augmented Generation (RAG)
- Introduction to RAG patterns
- Integrating Azure AI Search with Azure OpenAI
- Building a knowledge-grounded Q&A solution

### Module 5: Building Generative AI Applications
- Designing conversational AI experiences
- Implementing responsible AI practices
- Deploying and monitoring generative AI solutions

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/true-while/AI-3016.git
   cd AI-3016
   ```

2. Follow the lab instructions provided in each module's folder.

3. Ensure you have configured your Azure OpenAI credentials before running any exercises.
